# Create: Mob Grinding 1.5.4

## New Features
* Jade now shows how many chunks are stacked in the Rotational Mob Spawner and how many mobs it spawns per cycle.
* New advancements: fill a spawner with the maximum number of chunks, open a Spawner Chunk Bag, install a Fan Filter Upgrade and set a Vacuum filter on the Grinder.

## Bug Fixes
* The spawn progress line in Jade now shows up (it never did before).

## Other
* Releases now publish to GitHub too, with the same changelog as CurseForge and Modrinth.
