# Create: Mob Grinding 1.5.1

## Changes
* The Rotational Mob Spawner now spawns mobs like a vanilla spawner: at a random spot up to 4 blocks away, from one block below to one block above it. It doesn't need a floor, only room for the mob.
* New `spawnRange` config option to change the spawn area (set it to 1 for compact farms).
* Netherite Blade damage raised from x8 to x12 (24 damage per hit).
* Grinder damage now ignores armor.

## Config
* The Netherite Blade multiplier is now `netheriteBladeDamageMultiplier`, so the new value applies to existing configs too. If you had customized the old `netheriteDamageMultiplier`, set the new option again.
